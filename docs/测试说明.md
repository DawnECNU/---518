# 测试用例说明（阶段一）

## 1. 测试目标与范围

本测试文档对应阶段一初始需求，覆盖：

- 用户注册、登录和问卷数据隔离；
- 创建问卷和添加四类题目；
- 单选、多选和数字条件跳转；
- 必答、数量、长度、整数和范围校验；
- 逐题保存、提交检查和最终提交；
- 整卷统计和单题统计；
- 匿名、重复填写、关闭问卷和截止时间；
- CSRF 防护和真实 HTTP 全流程。

测试采用自动化 API/集成测试、业务逻辑单元测试和真实 HTTP 冒烟测试。

## 2. 测试环境

| 项目 | 值 |
| --- | --- |
| 测试日期 | 2026-10-22 |
| Python | 3.12.8 |
| MongoDB | 8.3 |
| Flask | 3.1.3 |
| PyMongo | 4.18.1 |
| 测试框架 | Python 标准库 `unittest` |
| 测试数据库 | 每个用例独立的随机数据库名，位于 `127.0.0.1:27017` |

测试前必须启动 MongoDB。Windows 环境下如果测试截止时间或提交成功页，建议在 Python 环境中安装 `tzdata`。

## 3. 运行方式

在项目目录执行：

```powershell
cd "C:\Users\Lenovo\Desktop\当代数据管理系统第一次大作业\阶段一代码"

# 如果使用项目的虚拟环境
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install tzdata==2025.3

$env:TEST_MONGO_URI = "mongodb://127.0.0.1:27017"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

如果使用系统 Python，把 `.\.venv\Scripts\python.exe` 替换为 `python`。

测试隔离规则：

1. 每个测试用例创建唯一数据库；
2. 测试安装 MongoDB Schema 和索引；
3. 用例结束后删除测试数据库并关闭 MongoClient；
4. 不读取、不修改正式数据库 `survey_phase1`。
